# Pomodoro Timer - React Hooks

Proyecto que implementa un temporizador Pomodoro usando:

- useState
- useEffect
- useRef

## Niveles

### Nivel 1
Timer básico con cuenta regresiva

### Nivel 2
Modo trabajo/descanso + historial

### Nivel 3
Configuración, progreso y estadísticas

## Ejecutar

npm install
npm start
